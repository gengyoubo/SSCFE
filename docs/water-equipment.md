# 美西螈储水装备

实现 [Issue #1](https://github.com/gengyoubo/SSCFE/issues/1) 中的湿润的月之尘、保湿剂、储罐核心、大储罐和以水为食。水的咒力及其技能留待后续实现。

评论中补充的月之适配附魔书与可食用月尘也已实现，见 [月之适配说明](moon-adaptation.md)。

## 使用

饰品效果只对美西螈形态生效，佩戴需要 Curios。普通流体储存、放置和管道连接可以独立使用。

五个新增物品均可在 SSCF 的创造模式物品栏中找到。

| 物品 | 槽位 / 容量 | 行为 |
| --- | --- | --- |
| 保湿剂 | 腰带 / 3,000 mB | 在水中自动装满。干燥陆地每 20 游戏刻消耗 2 mB，暂停核心模组的湿润度下降；水耗尽后恢复原来的下降规则。 |
| 大储罐 | 背部 / 32,000 mB | 必须手动注水。为佩戴的保湿剂补水；佩戴期间移动速度乘以 0.9。卸下或离开美西螈形态后恢复。 |
| 以水为食 | 护符 | 饥饿值低于 20 且湿润度大于 0 时，每 20 游戏刻消耗 1 点湿润度，恢复 1 点饥饿值和 1 点饱和度。 |

保湿剂和大储罐：一只手持储水物品，另一只手持水桶或空桶，在空中右键储水物品，可注入或取出一桶水。保湿剂也可在水中自动装满。

大储罐可以直接放置。手持水桶右键方块注水，手持空桶右键取水；其他交互显示水量。连接 Forge 流体管道可注水或取水。用镐采集后水量保存在掉落物中，再次放置时恢复。罐体窗口透明，内部水面按实际水量在 0～32 B 之间升降；空罐不显示水，管道抽水后水位同步下降。物品栏使用独立的固定图标。

## 配方

所有配方产出一个物品。配方中的水桶使用后留下空桶。

| 产物 | 九宫格（从上到下） | 字母 |
| --- | --- | --- |
| 湿润的月之尘 | ` Y ` / `YXY` / ` Y ` | X：未加工的月之尘；Y：水桶 |
| 保湿剂 | `XYX` / `XYX` / `XYX` | X：湿润的月之尘；Y：空桶 |
| 储罐核心 | `YXY` / `XXX` / `XYX` | X：空桶；Y：铁锭 |
| 大储罐 | `YXY` / `YXY` / `YXY` | X：储罐核心；Y：下界合金碎片 |
| 以水为食 | `XYX` / `XZX` / `XYX` | X：铁锭；Y：湿润的月之尘；Z：储罐核心 |

## Forge 接口与验证

储水物品暴露 `ForgeCapabilities.FLUID_HANDLER_ITEM`，水量存放在 Forge 标准 `Fluid` NBT 中。大储罐方块在所有方向暴露 `ForgeCapabilities.FLUID_HANDLER`，由只接受水的 `FluidTank` 实现；支持模拟/执行填充和抽取、方块实体持久化及客户端同步。

`AxolotlWaterService.consumeWater(player, amount)` 供后续饰品或招式消耗佩戴大储罐中的水，单位 mB，须在服务器线程调用。水量不足时返回 false，并且不扣除部分水量。

在 Java 17 环境执行 `./gradlew runGameTestServer`。六个储水游戏测试覆盖物品能力和保存、方块能力和水桶交互、水位比例及客户端同步数据、保湿 Mixin、供水/饥饿/速度联动及配方；另有四个月之适配与食物测试。测试源码和结构仅参与测试启动，不进入发布 JAR。游戏测试验证水位数据，不替代客户端渲染的人工检查。
