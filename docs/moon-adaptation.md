# 月之适配与可食用月尘

按 [Issue #1 评论](https://github.com/gengyoubo/SSCFE/issues/1#issuecomment-6077335631) 实现。

月之适配是一级附魔，适用于可损坏的穿戴装备，包括盔甲和鞘翅。一本书、一个塑形核心、七份未加工的月之尘无序合成真正的附魔书；用铁砧应用后保留装备已有附魔。装备可无视 SSCF 的形态穿戴限制，支持物品栏穿戴、右键穿戴、服务器维护及形态切换。绑定诅咒和原版装备槽位规则仍按原版处理。

适配装备可在铁砧中用未加工的月之尘修复，每份最多修复最大耐久的四分之一；原有修复材料仍有效。铁砧按正常规则计算经验费用和累积惩罚。未附魔的普通装备不会自动获得月尘修复能力；塑形盔甲原有月尘修复功能保留。

可食用月尘：`XYX / YXY / XYX`，X 为任意食物，Y 为未加工的月之尘，产出五份。五个食物格允许使用不同食物。通过 SSCF 的 `ignore_diet` 标签及物品使用豁免允许所有形态食用；使用固定营养路径，兼容旧版核心中的形态食物修正，每份恢复 3 点饥饿值和 3 点饱和度，遵循原版上限。图标沿用核心模组月之尘材质。

两者均加入 SSCF 创造模式物品栏。JEI 显示工作台配方、附魔书应用、适配装备的月尘修复及中英文说明。该附魔通过配方获得，不参与附魔台或村民交易抽取。

在 Java 17 环境执行 `./gradlew build runGameTestServer`。新增测试覆盖两份配方、真实铁砧应用与修复、穿戴限制与换形、所有已注册形态的进食恢复量；测试源码不进入发布 JAR。
