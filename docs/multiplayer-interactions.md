# 多人互动

默认按住 **G**，对其他玩家按右键。可在「选项 → 控制 → 按键绑定 → SCCFE」修改「多人互动」键。

## 美西螈叠罗汉

- 双方均需处于美西螈形态。右键目标可以是叠罗汉中的任意一层，新玩家会加入最上层。
- 底层与上层均保持匍匐姿态；上层紧贴下层：每层只比下层高 0.2 格、向后错开 0.35 格，模型允许互相穿插，使整叠紧凑地压在底层玩家身上。底层控制移动和排列朝向，最多八名玩家。
- 按潜行键退出：上层离开当前承载者，底层放下背上的玩家。中间层退出时同时断开上下两侧的连接。
- 死亡、离线、切换维度、变成其他形态或进入飞行等不兼容状态时，自动解除相关连接。
- 服务端检查形态、距离、视线与上方空间；普通右键保持原有行为。

## 蜘蛛鞍

- 物品「蜘蛛鞍」使用原版鞍的外观，只有蜘蛛最终形态（`shape-shifter-curse:spider_3`）能装备到 Curios 背部栏位（需安装 Curios）。
- 合成：`SES / LXL / S S`，S 为线，E 为蜘蛛眼，L 为皮革，X 为鞍；获得鞍后解锁配方。
- 装备后，蜘蛛腹部会显示原版鞍（跟随腹部动画）。普通玩家或人形形态玩家直接右键该蜘蛛玩家即可骑乘，骑手坐在蜘蛛腹部（静止时约身后 0.5 格、离地 0.15 格，并随腹部动画一起平移和转动），蜘蛛玩家照常控制移动。每只蜘蛛只能载一人；潜行时右键不会骑乘。
- 不能骑乘：野兽体型形态（FERAL）、美西螈最终形态、蜘蛛最终形态，以及飞行、睡觉、旁观等状态。
- 骑手按潜行键下来。蜘蛛卸下鞍、离开最终形态、死亡、离线或切换维度时自动解除骑乘；骑手离线时先下坐骑，避免蜘蛛玩家随之被卸载。

叠罗汉和蜘蛛鞍都通过原版玩家乘坐关系同步，旁观者及后来加入的客户端也会收到叠罗汉状态。
