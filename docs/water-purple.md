# 水的咒力与「水·茈」

实现依据：[Issue #1](https://github.com/gengyoubo/SSCFE/issues/1) 与后续施法规则。

## 饰品与操作

美西螈形态可装备护符 `sscfe:water_curse`。配方 `XYX / YZY / XYX`，X 为湿润的月之尘，Y 为铁锭，Z 为下界合金碎片。

- 手持饰品，Shift＋右键循环水拳／武器水附着／水盾／水·茈；普通右键切换对应开关，或切换水·茈的普通／特殊版本。
- 装备后也可以双手空手右键配置；这时会拦截普通方块交互。
- 水拳、水附着、水盾各自保存开关。切换到水·茈后，已开启的水盾仍然有效。
- 普通近战水伤为原伤害的 1.5 倍，烈焰人和岩浆怪为 2.5 倍；每次成功进入伤害处理消耗 1 点湿润度。
- 水盾先抵消 5 点，再对剩余伤害减免 10%；每次防御消耗 1 点湿润度。
- 选择水·茈后，瞄准并点击 **V**（可在键位设置中修改），即开始自动施法。再次点击 V 主动取消。

整个施法期间锁定当前位置和视角，禁止移动、跳跃和转向；发射沿开始时记录的方向。服务器拒绝移动／视角数据包，客户端屏蔽移动与鼠标输入。不能在乘骑、睡眠或鞘翅滑翔中开始施法。

实际生命伤害大于零时打断；完全被水盾、护甲或吸收生命挡下的攻击不打断。死亡、退出、换维度、换形态、卸下饰品、修改模式也会取消。正常发射和取消都会解除锁定并停止本次音乐。

## 时间、威力与消耗

玩家在 `config/sscfe-client.toml` 配置普通与特殊时间：

```toml
[water_purple]
cast_ticks = 600                    # 默认普通版 30 秒
particles_per_tick = 64

[water_purple_special]
special_charge_ticks = 600          # 默认 30 秒；57 秒只是示例（1140 Tick）
enabled = true                     # 本客户端是否收听特殊版音乐
sound_id = "sscfe:music.water_purple_special"
volume = 1.0
music_start_delay_ticks = 0
```

20 Tick = 1 秒。服务端在世界的 `serverconfig/sscfe-server.toml` 设置允许范围，默认最短 60 Tick（3 秒），最长 12000 Tick（10 分钟）。两种版本均经过服务端校验。服务器时间是施法依据，声音加载或客户端卡顿不改变发射时间。

低于 600 Tick，伤害、射程、伤害半径、水和湿润度消耗按 `施法 Tick / 600` 比例缩放；破坏半径向上取整，最低 1 格。达到 600 Tick 后封顶：3000 格射程，25 格伤害半径，每 Tick 25 点伤害、持续 20 Tick（500 点／秒），8 格破坏半径，32000 mB 水以及最大湿润度的 50%。更长时间只增加演出时间。

开始时检查资源，成功释放时再次检查并一起扣除。打断和主动取消不扣释放费用；已开启的水盾、以水为食、保湿剂等仍按各自规则消耗资源。资源在施法途中不足会取消。释放后冷却 10 秒。

普通地形无掉落，矿石按 10% 概率执行正常工具掉落。硬度 ≥50、不可破坏方块、容器／机器／其他方块实体及含流体的方块跳过；执行 Forge 方块破坏事件与交互权限检查。不会强制加载沿途区块，因此只影响已经加载的实体与地形。地形清除按全服每 Tick 的候选检查预算分批执行，默认 8192；伤害独立于清除队列。全服最多同时处理 8 道已释放的攻击，超限的施法取消且不扣费。服务器可设置 `break_blocks = false` 禁止地形清除。

## 怎样播放音乐

1. 复制仓库的 `examples/water-purple-music-pack` 文件夹到 Minecraft 的 `resourcepacks` 文件夹。
2. 将合法获取的歌曲转换为 **Ogg Vorbis**，命名为 `water_purple_special.ogg`，放到 `assets/sscfe/sounds/music/`。
3. 在游戏资源包界面启用该资源包。`pack.mcmeta` 应位于资源包根目录；压缩成 ZIP 也应保持这个结构。
4. 美西螈形态装备水的咒力，切换到水·茈特殊版，点 V。全服在线玩家会收到开始消息，各自在本地播放所配置的音效 ID。

模组预注册 `sscfe:music.water_purple_special`，默认声音列表为空。模板中的 `sounds.json` 用同一个事件 ID 引用音乐文件并设置 `stream: true`。服务器广播技能事件，不上传、下载或转发音乐；**每位想听到歌曲的玩家都需要启用自己的音乐资源包**。不同玩家可以配置不同歌曲，或设置 `enabled = false` 静音。

无音乐资源包、未知音效 ID 或空事件会安静回退；普通蓄力和释放音效仍播放。取消／受伤／释放消息停止对应声音实例，多个施法者的音乐状态独立，不停止其他游戏声音。重载资源时由 Minecraft 声音引擎停止旧声音；不会自动重播。中途加入的玩家只恢复正确进度的视觉演出，不从歌曲开头补播。

`music_start_delay_ticks` 是开始施法后等待多久才播放音乐，**不是在 OGG 中跳转到某个时间点**。Minecraft 的流式声音接口不提供可靠的歌曲进度定位；若希望从歌曲中段开始，先裁剪 OGG。如果高潮在该文件的第 57 秒，将特殊版时间设为 1140 Tick 即可；如延迟 2 秒播放，需相应把施法时间设为 1180 Tick。网络和音频加载延迟可能产生小幅演出偏差，不承诺采样级同步。

## 蓝色特效

名称仍为「水·茈」，核心按水系设计为蓝色：浅蓝与深蓝能量球汇聚，蓝色内核与水流环逐渐扩大，出现竖直水柱，释放时高速蓝色球体沿锁定方向前进。采用专门的几何渲染与有上限的本地粒子，减少服务器逐粒子广播。演出使用已有 `mizu_mulasaki1`／`mizu_mulasaki2` 动画。

`mizu_mulasaki1` 从施法开始正向播放并保持末帧；两秒长的 `mizu_mulasaki2` 在发射前两秒正向播放。例如 30 秒施法在第 28 秒开始编号 2，30 秒播放结束时发射。自定义时间也按同一规则计算；取消或打断立即解除动画。

音乐跨维度广播；视觉仅在施法者所在维度显示，且受客户端距离限制（几何 512 格、粒子 256 格）。不会在聊天中广播坐标。降低 `particles_per_tick` 可减少粒子负担。

## 游戏内验证

- 两个客户端启用音乐包，特殊版设为 60 Tick；点击 V 后双方听到歌曲，施法者不能移动／转向，3 秒后自动释放并停止音乐。
- 普通版 600 Tick 与特殊版 1140 Tick，检查后者不增加威力；比较 60 Tick 的资源费用和范围。
- 施法中受到生命伤害、死亡、退出、换维度、卸下饰品或主动取消，双方音乐与演出停止，释放费用未扣。
- 开启水盾，用 ≤5 点攻击测试完全抵消不打断，再用更高伤害测试打断。
- 卸载音乐包、静音、改为无效／不存在的 ID、调低声音类别“音乐”音量，技能应继续正常执行。
- 中途加入、多位玩家同时施法、资源重载：检查不会重启已播歌曲，不会误停其他人的声音。
